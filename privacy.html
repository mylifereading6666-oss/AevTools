AevTools プライバシーポリシー

制定日：2026年11月7日

AevTools（以下「本サービス」）は、利用者の情報を適切に取り扱うため、以下の方針を定めます。

1. 本サービスについて

本サービスはGitHub Pages上で提供されるウェブツール集です。タスク、タイマー、メモ、収支などの機能に加え、Supabaseによるアカウント認証や、任意のYouTubeサポーター実績確認機能を提供します。

2. 保存する情報

  • ブラウザ内のデータ：タスク、メモ、タイマー記録、設定、実績などの一部は、利用者のブラウザのlocalStorage等に保存されます。端末やブラウザのデータを消去すると、これらが失われる場合があります。
  • アカウント情報：登録・ログインを利用する場合、メールアドレスや認証関連情報は認証サービスSupabaseにより処理されます。パスワードはSupabaseの認証機能で管理され、本サービスが平文で保存するものではありません。
  • プロフィール情報：ニックネームはSupabaseに保存され、ルーレット参加者一覧、サポート会話、個別チャットなど、他の利用者に表示される場合があります。
  • ルーレット機能：参加した場合、アカウントID、ニックネーム、参加日時、抽選結果がSupabaseに保存されます。参加者一覧と抽選中の状態はログイン中の利用者にリアルタイム表示されます。当選確率の調整値は管理者のみが閲覧できます。
  • 当選者チャット：当選者と管理者の間で送受信したメッセージがSupabaseに保存されます。管理者がチャットを完全削除すると、チャットとメッセージも削除されます。
  • サポート機能：サポートリクエスト等を利用した場合、入力内容や処理状況がSupabaseのデータベースに保存されることがあります。
  • YouTube実績確認：利用者が任意でGoogle認証を行うと、YouTubeチャンネル登録状態の確認に必要なGoogleアカウントの認可情報が、その処理中に利用されます。Google OAuthクライアントIDとYouTube APIキーはサイトの公開コードから読み込まれます。APIキーにはGoogle Cloud側でHTTPリファラーおよびYouTube Data API v3の制限を設定します。Googleのアクセストークン等の認証情報を他人と共有しないでください。

3. 外部サービス

本サービスは、GitHub Pages（ウェブサイト配信）、Supabase（認証・データベース）、Google OAuthおよびYouTube Data API（任意の登録状態確認）、Google Identity Services等の外部サービスを利用します。各サービスによる情報の取り扱いは、それぞれの提供者のプライバシーポリシーや規約にも従います。

  • GitHub プライバシー声明
  • Supabase プライバシーポリシー
  • Google プライバシーポリシー

4. 利用目的

情報は、サービスの提供、アカウント認証、サポート対応、設定や記録の保存、YouTube実績の確認、不正利用の防止およびサービスの維持のために利用します。

5. 第三者提供

法令に基づく場合を除き、利用者の情報を販売しません。サービスの提供に必要な範囲で、上記外部サービス事業者に情報が処理されることがあります。

6. 利用者による管理・削除

ブラウザに保存されたデータは、ブラウザのサイトデータ削除や本サービス内の各機能から管理できます。アカウント情報やサポートデータの削除を希望する場合は、GitHubリポジトリの連絡窓口からお問い合わせください。外部サービスに保存された情報は、各サービスの手続きが必要となる場合があります。

7. 未成年者の利用

未成年者が本サービスを利用する場合は、保護者の方と相談したうえで利用してください。GoogleやSupabaseなど外部サービスの年齢条件・利用規約も確認してください。

8. ポリシーの変更

機能や法令の変更に応じて、本ポリシーを更新することがあります。変更後の内容はこのページに掲載します。

9. お問い合わせ

本ポリシーや情報の取り扱いについては、AevToolsのGitHubリポジトリからお問い合わせください。
